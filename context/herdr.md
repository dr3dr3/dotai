# Herdr — layout and messaging rules

Inside Herdr (`HERDR_ENV=1`), load the `herdr` skill before creating panes or tabs or sending to another pane. In short: split `right`, never `down`; label every pane you create `<role>·<harness>`; never make a third pane in a tab; stage commands into André's `term` tab without pressing Enter; never type into another agent's input box unless it is empty; close what you open and nothing else. Full reference: dotfiles `docs/herdr-conventions.md`.
